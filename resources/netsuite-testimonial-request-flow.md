# NetSuite Email Template Service Testimonial Request Flow

## When to Ask

Ask after:

- final template approval
- successful internal upload or campaign preparation
- the client confirms the template is easier to edit or use

Do not ask while unresolved defects or revision issues are open.

## First Request

```text
Hi {{first_name}},

Glad the template is now handed over.

If the project has been useful, could you send a short testimonial I can use for the NetSuite-compatible email template service?

Two or three sentences is enough. The most useful angle would be what changed compared with the old template, for example easier editing, cleaner mobile rendering, or faster campaign preparation.

If you prefer, I can draft a short version for approval.

Matthew
```

## Draft for Client Approval

```text
Template Hedgehog helped us rebuild our NetSuite campaign email template into cleaner responsive HTML. The new version is easier to edit, works better on mobile, and gives our team a more reliable base for future sends.
```

## Permission Questions

Ask:

- Can we use your name and company?
- If not, can we use an anonymised version?
- Can we show before/after screenshots?
- Can we mention the package delivered?
- Can we mention the measurable outcome?

## Follow-Up

```text
Hi {{first_name}},

Just following up on the testimonial request.

An anonymised version is completely fine if that is easier. I am mainly looking to capture the practical result of the template work, not make a big public claim.

Matthew
```

## Storage

Record:

- testimonial text
- approval status
- approved attribution
- date approved
- where it can be used
- any restrictions
