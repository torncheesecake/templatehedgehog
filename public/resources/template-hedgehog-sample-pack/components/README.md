# Components

Paid archives include reusable MJML components with compiled HTML output.

This sample layout is assembled from these production blocks:

- header-brand-row: Creates immediate sender recognition.
- welcome-email-hero: Leads with the welcome message and product promise.
- onboarding-step-card: Turns onboarding into one explicit next step.
- app-download-strip: Keeps the product accessible after the first login or setup step.
- footer-onboarding-legal: Finishes with lifecycle-appropriate support language.
