# Template Hedgehog Studio Positioning

Core phrase:

Everything before send.

Template Hedgehog Studio is the workspace powered by the Template Hedgehog library. It handles authoring, compile, QA, preview, and handoff for production email systems before they move into a sending platform.

Mailchimp, Klaviyo, HubSpot, NetSuite, Salesforce, Customer.io, and similar platforms handle delivery, audiences, automation, unsubscribe, and reporting. Studio handles the production artefacts that come before that stage.

## Plain Comparison

Mailchimp:

- sends
- automates
- reports
- manages audiences

Studio:

- builds
- compiles
- checks
- previews
- prepares handoff

## Practical Boundary

Studio does not replace Mailchimp, Klaviyo, HubSpot, NetSuite, Salesforce, Customer.io, or other sending systems. It prepares MJML source, compiled HTML, workflow structure, QA notes, preview references, and platform handoff guidance for the platform a team already uses.
