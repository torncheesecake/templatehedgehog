# Template Hedgehog Project Brief

## Design North Star

Template Hedgehog should feel like:

- Linear-level product proof
- Resend-level developer clarity
- Ghost-level editorial calm

The product story should prove value through real production artefacts, not through marketplace-style browsing or feature volume.

## Avoid

- Template marketplace language
- Feature dumping
- SaaS card grids
- Visual overload

## Prefer

- Workflow proof
- Source-to-handoff artefacts
- Calm typography
- Premium restraint
- Operational outcomes
